# Simple Calculator

A basic calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- Add, subtract, multiply, divide, percentage
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Clear (C) and backspace (⌫) buttons

## Usage
Open `index.html` in any browser. No build step or dependencies required.
